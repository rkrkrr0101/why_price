# 이거왜오름 (Why Price)

급등락 주식의 변동성 원인을 분석하고 레포트를 제공하는 웹 서비스입니다.

## 프로젝트 구조

이거왜오름 프로젝트는 다음과 같이 3개의 주요 컴포넌트로 구성되어 있습니다:

1. **웹 서버 (현재 프로젝트)**
   - 배치 프로세스가 생성한 레포트를 표시
   - MCP (Microservice Control Plane) 서버 역할
   - Spring Boot 기반 Kotlin 애플리케이션

2. **배치 프로세스**
   - 주식 레포트 생성
   - RAG 데이터 처리

3. **Python 프로세스**
   - RAG 데이터 추가 및 관리
   - 뉴스 데이터 처리 및 벡터화

## 주요 기능

- 주식 레포트 조회 및 표시
- MCP 서버 기능 제공

## 기술 스택

- Kotlin
- Spring Boot
- JPA
- MySQL

## 환경 설정

1. `.env.example` 파일을 `.env`로 복사하고 필요한 환경 변수를 설정합니다.

## 개발 중인 기능

- 비동기 처리 최적화
- RAG 시스템 통합
- 컨트롤러 테스트 개선
- 예외 처리 강화
- GPT 프롬프트 튜닝
